# Sunshine Equity — AI brain (demo)

Fictional growth-equity firm knowledge base for product demos.

Nothing in this repository is real. Company names, people, financials, deal
terms, and documents were invented for walkthroughs. Do not treat any figure
or name as a live investment.

## Layout

| Path | Use for |
|------|---------|
| [firm/](./firm/) | Curated firm brain — start at [firm/overview.md](./firm/overview.md) |
| [firm/GLOSSARY.md](./firm/GLOSSARY.md) | Firm language |
| [firm/team/](./firm/team/) | People and roles |
| [firm/playbooks/](./firm/playbooks/) | How to produce firm deliverables |
| [firm/research/](./firm/research/) | Non-canonical investigations |
| [neutron/](./neutron/) | Published wiki evidence (demo corpus) |

## Suggested walkthrough

1. Open [neutron/index.md](./neutron/index.md).
2. Open a company page, e.g. [HelioGrid](./neutron/companies/heliogrid.md).
3. Follow a Subject document into an IC memo or board pack.
4. Open the linked source only if you want the “converted original.”

## Origin

Mirrors the folder shape of a real firm brain (curated `firm/` plus published
`neutron/`). All content here is Sunshine Equity fiction.
